# 30分スタディ Ver.0.13

中学生向けの小テスト・定期テスト対策Webアプリです。Cloudflare Pages（HTTPS）での利用を前提にしています。

## Ver.0.11 の変更

- 定期テストの出題範囲で単元を選んでも、その教科パネルを開いたままに変更
- 通常解説に加えて「AIで詳しく解説」を追加
- AI解説はユーザーがボタンを押したときだけ実行

- 氏名、テスト名、OCR全文、学習履歴、ユーザーIDはAI解説APIへ送信しない
- AI呼び出しはCloudflare Pages Function経由で行い、ブラウザへAPIキーを置かない
- AIが利用できない場合も、既存の解説だけで学習を継続可能

## Cloudflare Workers AI の設定

Ver.0.11のAI解説を使うには、Cloudflare PagesプロジェクトにWorkers AI bindingを追加してください。

1. Cloudflare Dashboardで対象のPagesプロジェクトを開く
2. Settings → Bindingsへ進む
3. Workers AIを追加
4. Variable nameを `AI` にする
5. 保存後にPagesを再デプロイする

`wrangler.toml` にも次の設定を含めています。

```toml
[ai]
binding = "AI"
```

AI bindingを設定しなくても、小テスト・定期テスト・OCR・通常解説は利用できます。「AIで詳しく解説」だけが利用できません。

## AI解説で送信しないデータ

AI解説エンドポイント `/api/explain` は、ブラウザから送信された問題文と正解など学習に必要な最小限の内容だけを受け取ります。登録済みテスト名、氏名欄、OCRの元画像/PDF、学習履歴は送信しません。

## 公開

## v0.17.1 国語の教科書会社

国語を選ぶと、静岡県の採択地区を選択できます。地区に応じて令和7〜10年度の国語教科書会社を自動候補として設定し、必要なら手動変更できます。今後、教科書固有問題には `textbookPublisher` を付与し、共通問題は `common` のまま利用できます。


## v0.18 静岡県の9教科教科書自動設定

ホームの「教科書設定」から静岡県の採択地区を1つ選ぶと、令和7〜10年度に市町立中学校で使用される9教科の教科書会社をまとめて設定します。

- 国語：国語・書写
- 社会：地理・歴史・公民・地図
- 数学
- 理科
- 音楽：一般・器楽合奏
- 美術
- 保健体育
- 技術・家庭：技術・家庭
- 英語

問題データに `textbookPublisher` が設定されている場合は、選択した採択地区の教科書会社に合う問題だけを出題できます。出版社指定のない既存問題は共通問題として引き続き出題します。

データ出典：静岡県教育委員会「中学校教科用図書一覧（令和7～10年度使用）」。市町立中学校向けの採択結果です。

## v0.19 教科書の手動変更と教科書別の登録問題

- 採択地区から自動設定した教科書を、教科・分冊ごとに手動変更できます。
- 手動変更した項目には「手動設定」と表示されます。
- 「手動変更をすべて解除」で地区の自動設定へ戻せます。
- 紙から登録した問題を「共通問題」または「現在設定中の教科書に限定」として保存できます。
- 教科書限定問題は、設定中の出版社と一致するときだけ出題候補になります。

## v0.20.2 教科書の教材 / Unitプリセット

- 国語・英語について、現在設定中の教科書会社と学年ごとに「教材名 / Unit名」を登録できます。
- ページ範囲（例：p.42〜57）は任意で保存できます。
- 教材 / Unitに、アプリ内の関連単元を複数紐付けできます。
- 小テスト画面では登録した教材 / Unitを押すだけで、関連単元を一括選択できます。
- 教科書本文は保存せず、教材名・ページ範囲・単元の対応だけを端末内に保存します。
- 教材プリセットはバックアップ / 引き継ぎ対象です。


## v0.21 年度・出版社・学年から教材 / Unit候補を表示

定期テストの登録・編集画面で、教科書年度（令和7〜10年度）、学校設定で選ばれている出版社、学年を組み合わせて、国語の教材名と英語のUnit / Lesson候補を自動表示します。候補を押すと、その教材に関連するアプリ内単元が出題範囲へ追加されます。候補は出版社が一般公開している令和7年度版の目次・年間指導計画などを基にしています。出版社・学年によって公開情報の粒度が異なるため、候補がない場合や詳細が不足する場合は、従来どおり単元一覧から手動選択できます。
