## 3. 本番で未確認のこと・Cloudflare 管理画面でオーナーが行う操作（実施していない）
1. **プレビュー環境で確認する**：本番公開の前に、Cloudflare Pages のプレビュー URL で次を確認する。
   - `/README.md` と `/functions/api/explain.js` が 404 になること
   - `/` に Content-Security-Policy ヘッダが付くこと
   - OCR（紙テストの読み取り）と PDF 読み込みが動くこと：CDN を使うため、この環境ではネットワーク制限で検証できていない
   - AI 解説が1回動くこと
   - `_routes.json` が受け付けられること：ローカルの wrangler では確認済み
2. **AI 解説の上限を確実にする（推奨）**：Workers KV の名前空間を作り、Pages プロジェクトの Functions に `EXPLAIN_LIMITS` という名前で紐付ける。必要なら環境変数 `EXPLAIN_DAILY_LIMIT`（全体の1日上限、既定1000）と `EXPLAIN_DAILY_PER_CLIENT`（既定60）を設定する。
   - KV がなくても動くが、その場合の回数制限は実行環境ごとの目安にとどまる。
3. **WAF のレート制限ルール（推奨）**：`/api/explain` への POST を、IP あたり1分10回程度に制限する。
4. **利用量の監視**：Workers AI の使用量ダッシュボードと請求アラートを設定する。Functions のリアルタイムログでは `"evt":"explain"` で絞り込める。
