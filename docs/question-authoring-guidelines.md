# 問題作成・採点の注意事項

## 本文・設問と模範解答の一致

記述問題は、本文の文章を無意味に丸写しするだけで正答できる状態を避ける。
ただし、**本文中の語句を正しく取り出して使うこと自体が学習目標の問題**では、必要な範囲で本文と模範解答が一致してよい。

- 例：過去進行形の読解で `was reading a book` を用いて「その時にしていた行動」を答える場合。
- 照合ツールの `possible passage answer leakage` は診断用の警告であり、**機械的に文意を変えて消してはいけない**。
- 警告が出たら、問題の学習目標・出題文・模範解答が正しいかを人が確認する。
- 正当な一致の場合は、設問の `leakageReviewed` に「なぜ一致が必要か」を記録できる。警告抑制を導入する場合は、検証をすり抜けないよう別途回帰テストを作る。
- 誤答に限定語や無関係な話題を使わず、記述解説には採点観点を付ける。
- 既存の問題IDは変更せず、元の `data/questions.js` / `data/questions.json` は維持する。

このルールは、解答のコピーを促すことではなく、本文に忠実であるべき問いと、推論や言い換えを求める問いとを区別するためのもの。
